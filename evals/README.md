# Avaliação das skills

Este diretório contém especificações de casos para execução em ChatGPT/Codex. O CSV de conflitos **não é um teste de ativação já executado**: cada linha estabelece uma intenção e a skill esperada.

Para cada caso, executar o prompt em ambiente limpo, registrar skill selecionada, trace e resultado, e comparar com expected_skill. Incorporar casos negativos, inputs incompletos, segurança e retomada antes de declarar maturidade operacional.

A meta proposta é verificar acionamento, não apenas validar YAML. Dados de produção e informações restritas não devem integrar fixtures públicas.
